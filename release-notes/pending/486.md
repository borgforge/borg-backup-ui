### Before updating

- Back up your configuration and data directories before installing this update. (#486)
- The one-time job migration may take several minutes. The web interface starts afterwards. Follow progress in `/var/log/borg_backup_ui.log` and let the migration finish. (#486)

### Improvements

- **Permanent job IDs:** Every job now keeps the same identity throughout the application. (#486)
    - Rename jobs or change their full archive prefix while keeping schedules, history and restore results associated with the job.
    - Jobs remain sorted by name. The ID is visible in the Job Wizard and History details.
    - New log and status filenames include the job name, location and ID for easier identification.
- The Job Wizard uses a consistent window size. Repository Maintenance shows retention in a table and clearly identifies the current archive filter used by prune. (#486)
- Current and previous archive prefixes cannot overlap with another job in the same repository. Previous prefixes remain available in Browse & Restore. (#486)
