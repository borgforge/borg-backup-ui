### Improvements

- Manage reusable Bash scripts in Settings and select general Pre/Post hooks in the job wizard. Pre runs before backup preparation; Post runs after maintenance and cleanup, optionally also on failure, skip or cancellation. Includes syntax validation, timeouts and separate script outcomes in history. Central edits apply to the next run; active runs retain their script snapshot. (#550)
- Match the script editor to the shared Settings card layout and keep History detail backgrounds uniform, including optional script results. (#550)
- Show which jobs use each script in a compact expandable list, including Pre/Post conditions, and add Bash syntax highlighting, line numbers and navigation to syntax errors in the editor. (#550)
- Duplicate scripts and import/export Bash .sh files. Imports require a Bash shebang and valid syntax; duplicates and imports open unassigned drafts for review before saving. (#550)

### Bug Fixes

- Clearly identify Pre/Post failures and script exit codes in History and logs. A failed Pre reports that the backup was not started; log completion headings reflect failure, cancellation or warnings. (#550)
