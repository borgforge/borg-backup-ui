### Security

- Update bundled certifi, OAuthlib and urllib3 to address the upstream certificate-trust, OAuth and HTTP/TLS advisories reported by dependency scanning. (#672)

### Migration and compatibility

- Upgrade Apprise from 1.13.1 to 2.1.0 with 158 available base providers. Existing profiles and secrets are preserved. Amazon Chime is retired; affected profiles show a warning and need another provider. URL options are validated more strictly, and legacy PGP email options have changed; see the provider inventory. No credentials or saved URLs are automatically converted. (#672)

### Bug Fixes

- Honor notification timeouts in worker threads and profile tests. Timeouts count as failed attempts, but already running requests may still arrive later and retries can cause duplicate notifications. Keep late provider logs private. (#672)
