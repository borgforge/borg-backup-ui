### Bug Fixes

- Keep Borg repository security state across Unraid reboots so unencrypted backups no longer require a manual repository information refresh. Use the same persistent state for backup, maintenance and restore operations. (#498)

### Migration and compatibility

- Adopt existing Borg security records once into `borg-security` below the plugin configuration root (normally `/boot/config/borg-backup/borg-security`). Preserve a migration snapshot and the original records; conflicting copies stop migration with a logged error. Previously lost state is initialized on the next access to an explicitly unencrypted managed repository. Existing Borg key storage and backup archives remain unchanged. (#498)
