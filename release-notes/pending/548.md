### Migration and compatibility

- Include an isolated private Python runtime for Unraid 6.12.5 through 7.x. Python 3 for Unraid is no longer required by Borg Backup UI in this release. A compatible external interpreter remains preferred; the private fallback works without a Python download at boot. Other plugins may still need their own Python provider. Unraid 8 is not supported. Existing jobs, configuration, secrets and repositories are preserved. (#548)

### Improvements

- Show the selected Python runtime source, version and path in system health. Keep service, backup, restore and administrative helpers on the selected interpreter, with packaged dependencies isolated from host Python packages. (#548)
