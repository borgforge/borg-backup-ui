Issue #289: Repository info refresh controls

- Added a Settings > Repository area for controlling automatic repository information refreshes.
- Automatic repository info refresh can now be disabled to avoid waking spun-down Unraid array disks only for cached repository statistics.
- The refresh worker now schedules the next global run instead of waking every hour to check whether repository statistics are due.
- Settings show the worker state, plugin PID, last run, next run, latest result counts and optional per-repository details without running Borg commands.
