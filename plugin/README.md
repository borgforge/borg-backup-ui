**Borg Backup UI**

Unraid plugin for BorgBackup with a guided web interface for backup jobs,
repositories, restore tests, archive browsing, reports, notifications, and
system health checks.

Builds with #548 include private Python for Unraid 6.12.5 through 7.x. A suitable
external Python may be used without depending on its provider at boot. The first
stable release remains pending validation; see docs/maintainer/python-runtime.md.
